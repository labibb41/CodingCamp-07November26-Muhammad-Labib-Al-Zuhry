## ❓ Troubleshooting

### GitHub Pages Not Showing
- Wait 2-3 minutes (sometimes takes longer)
- Hard refresh browser (Ctrl+F5)
- Check Settings > Pages - is it enabled?
- Check branch is set to `main`

### Live Site Shows 404
- Verify URL format
- Check spelling of repo name
- Wait a bit longer
- Try in incognito mode

### Challenges Not Working
- Check browser console (F12) for errors
- Refresh page
- Try different browser
- Check localStorage has data

### Can't Find Submission Link
- Check Coding Camp email
- Ask instructor/admin
- Check class Discord/chat
